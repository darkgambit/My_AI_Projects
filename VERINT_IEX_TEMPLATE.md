# Verint + IEX Raw Template

`Verint_IEX_Raw_Template.xlsx` is a formula-driven WFM workbook that takes raw
interval exports from **Verint Workforce Management** and **IEX TotalView**, keeps
them untouched, calculates the same KPIs for both, and reconciles the two pulls
day by day.

It is generated by `build_verint_iex_template.py` and checked by
`qa_verint_iex_template.py`.

---

## Why two raw sheets, one schema

Verint and IEX exports rarely share column order, but they describe the same
object: a queue (skill), in a site, in an interval, with volume, handle time,
service level and staffing. The template fixes that canonical schema once and
uses it on both raw sheets, so:

* pasting is mechanical - align the export to the header row;
* every KPI is calculated twice, once per source, with identical logic;
* reconciliation becomes a straight comparison instead of a mapping exercise.

## Sheet map

| Sheet | Purpose |
| --- | --- |
| `README` | In-workbook guide, workflow, column dictionary |
| `Setup` | Period start/end, interval minutes, site/queue/channel filters, report source, tolerance |
| `Lists` | Sites, queues, channels - feeds every dropdown and the queue mix |
| `Verint_Raw` | Verint interval export, 10,000 row capacity, data only |
| `IEX_Raw` | IEX interval export, same schema and capacity |
| `Calc_Data` | Calculation engine: period totals, daily trend, interval profile, queue mix |
| `Dashboard` | 10 KPI cards, reconciliation strip, 4 charts |
| `Reconciliation` | Daily Verint vs IEX variance with tolerance flags |
| `DQ_Checks` | 20 data-quality rules (blanks, negatives, ratio sanity, coverage) |

## Canonical raw schema

| Column | Verint name | IEX name | Notes |
| --- | --- | --- | --- |
| Date | Date / Interval Date | Date / Start Date | Interval start date |
| Interval Start | Interval Start / Start Time | Interval / Start Time | Time only (`hh:mm`) |
| Interval End | Interval End / End Time | End Time | Optional |
| Interval | Interval / Interval Name | Interval Label | Display label |
| Site | Site / Location | Location / Site | Matches `Lists!A` |
| Queue / Skill | Queue / Queue Name | Skill / Skill Name | Matches `Lists!B` |
| Channel | Channel / Media Type | Channel / Media | Voice, Chat, Email, ... |
| Offered | Offered / Contacts Offered | Offered / Total Offered | Integer |
| Handled | Handled / Answered | Handled / Answered | Integer |
| Abandoned | Abandoned / Abandons | Abandoned | Integer |
| Short Abandoned | Short Abandoned | Short Abandoned | Optional |
| ASA (sec) | ASA / Avg Speed of Answer | ASA | Weighted by handled |
| AHT (sec) | AHT / Avg Handle Time | AHT | Cross-checked against talk+hold+ACW |
| Talk / Hold / ACW (sec) | Talk, Hold, ACW | Talk Time, Hold, ACW | Totals, not averages |
| Staffed (agents) | Staffed / Agents | Staffed / Staff | Average in interval |
| Required (agents) | Required / Needed | Required / Req | Interval requirement |
| Service Level % | Service Level / SL % | Service Level | Stored as `0.85`, shown as 85% |
| Max Wait (sec) | Max Wait / Longest Wait | Max Wait | Longest wait in interval |
| Source File | export name | export name | Traceability |
| Notes | Notes | Notes | Free text |

## Definitions used in the workbook

| Metric | Definition |
| --- | --- |
| Abandon rate | abandoned / offered |
| Service level | offered-weighted average of interval SL (not a plain average) |
| ASA | handled-weighted average of interval ASA |
| AHT | (total talk + hold + ACW) / handled contacts |
| Staffed / required agent-hours | SUM(staffed agents) x interval minutes / 60 |
| Staffing gap | required hours - staffed hours (positive = understaffed) |
| Occupancy | (talk + hold + ACW hours) / staffed agent-hours |
| Reconciliation flag | REVIEW when offered variance % or handled variance breaches the Setup tolerance |

## Workflow

1. `Setup!B5` - set the first day of the reporting month; period end is `EOMONTH`.
2. Paste the Verint export into `Verint_Raw!A6` and the IEX export into `IEX_Raw!A6`.
3. Delete the 96 yellow demo rows (`6:101`) on both raw sheets when you go live.
4. Run `DQ_Checks` - every `FAIL` is a source-data problem, not a formula error.
5. Choose `VERINT`, `IEX` or `COMBINED` on `Setup!B13`, then read the Dashboard.
6. Investigate `REVIEW` days on `Reconciliation`; widen or tighten the tolerance on `Setup!B20`.

## Design notes

* Raw sheets carry **no formulas** - imports cannot break the model, and the
  workbook stays fast at 10,000 rows per source.
* All aggregation runs on `Calc_Data` through workbook-level defined names
  (`VER_OFFERED`, `IEX_SL`, ...), so extending capacity means editing one name
  per field.
* Filters use `ALL` on Setup. SUMIFS receives a `*` wildcard through helper
  cells (`Calc_Data!D3:D5`), while SUMPRODUCT-weighted metrics use explicit
  `ALL`-or-match conditions - the two paths stay consistent.
* Interval matching rounds time bounds to 6 decimals, which removes the
  floating-point drift that silently drops the `08:00` interval.
* `Dashboard`, `Reconciliation`, `DQ_Checks` and `README` are set to landscape,
  fit-to-width for clean printing/PDF export.

## Rebuild and verify

```bash
python build_verint_iex_template.py     # writes Verint_IEX_Raw_Template.xlsx
python qa_verint_iex_template.py        # 70 structural + arithmetic checks
```

The QA script recomputes every headline KPI in pure Python from the raw sample
rows and compares them with the workbook's own formulas, recalculated through
the optional [`formulas`](https://pypi.org/project/formulas/) engine:

```bash
pip install openpyxl formulas
```

Expected sample result (COMBINED, 1-2 Oct 2026):

| Metric | Verint | IEX |
| --- | --- | --- |
| Offered | 1,980 | 1,964 |
| Handled | 1,774 | 1,752 |
| Service level | 83.35% | 83.38% |
| AHT | 375.95 s | 380.67 s |

The demo data contains two deliberate discrepancies so the reconciliation strip
shows one `MATCH` day and one `REVIEW` day.

## Limits

* 10,000 data rows per raw sheet (rows 6-10,005).
* Daily trend table covers 31 days; interval profile covers 48 intervals
  (24 h at 30 minutes). Extend those blocks for 15-minute intervals.
* Both sources must be in the same time zone - the workbook does not convert.
